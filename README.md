# Appetizers

Appetizers is a SwiftUI-based iOS application that allows users to browse a list of appetizers, view details, add them to an order, and manage their account. 
The app follows the MVVM architecture pattern and supports dark mode.

---

## 📱 Screens

1. **Appetizer Listing Screen:**  
   - Displays a list of appetizers fetched from a remote API.
   - Allows users to tap on an appetizer to view detailed information.
   - Option to add appetizers to the order.

2. **Account Screen:**  
   - Form to update user information such as name, email, and preferences.

3. **Order Screen:**  
   - Displays a list of appetizers added to the order.
   - Shows the total price and allows users to review their order.

---

## ✨ Features

- **SwiftUI Implementation:**  
  The entire app is built using SwiftUI, leveraging its declarative syntax and reactive state management.

- **MVVM Architecture:**  
  Utilizes the MVVM (Model-View-ViewModel) pattern to maintain a clean separation of concerns and promote testability.

- **Network Calls:**  
  Asynchronous network requests to fetch appetizer data.

- **Details View:**  
  A detailed view of each appetizer, including its description, price, and an option to add to the order.

- **Order Management:**  
  Functionality to add, review, and manage appetizers in the order.

- **Account Form:**  
  A form in the account section for updating user details.

- **Dark Mode Support:**  
  Seamless support for light and dark modes, adapting to system preferences.

---

## 🛠️ Tech Stack

- **SwiftUI:** UI Framework for building declarative user interfaces.
- **MVVM Architecture:** Separation of UI, business logic, and data management.

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/iRohitoz/appetizers.git
    ```

    ```bash
    cd appetizers
    ```
2. **Open in Xcode:**
    ```bash
    open Appetizers.xcodeproj
    ```

3. **Build and Run:**  
   - Ensure you have the latest version of Xcode installed.
   - Select a simulator or a connected device.
   - Click on **Run** or press `Cmd + R`.
